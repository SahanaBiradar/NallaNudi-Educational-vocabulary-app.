# NallaNudi - Educational Vocabulary App ✨

NallaNudi is a modern Kannada vocabulary learning Android app built using Kotlin and Jetpack Compose.

## Features 🚀

- 🔍 Word Search
- 🎤 Voice Search
- 🔊 Text To Speech Pronunciation
- ⭐ Save Favorite Words
- 🧠 Interactive Quiz
- 📚 Flashcards
- 📅 Word Of The Day
- 🌙 Dark Mode
- 🔔 Notifications
- 📊 Learning Progress Tracking

## Tech Stack 🛠

- Kotlin
- Jetpack Compose
- Room Database
- Coroutines
- Material 3
